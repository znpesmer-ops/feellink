## 🎯 Admin Paneli Nedir?

Admin paneli, platformun tüm verilerini görüntülemenize ve yönetmenize olanak sağlayan özel bir arayüzdür. Bu panel aracılığıyla:

- ✅ Kullanıcıları görüntüleyebilir ve yönetebilirsiniz
- ✅ Gönderileri izleyebilir ve yönetebilirsiniz
- ✅ Bildirimleri görüntüleyebilirsiniz
- ✅ İstatistikleri takip edebilirsiniz
- ✅ Sistem ayarlarını yapılandırabilirsiniz

**Erişim:** `http://localhost:3000/admin`

## 👤 Admin Olarak Nasıl Giriş Yapılır?

### Adım 1: Normal Kullanıcı Olarak Kayıt Olun

Eğer henüz hesabınız yoksa:

1. Tarayıcınızda `http://localhost:3000/register` adresine gidin
2. Formu doldurun:
   - Username: `admin` (veya istediğiniz kullanıcı adı)
   - Email: `admin@example.com`
   - Password: Güçlü bir şifre girin
   - Full Name: İsim ve soyisim
3. "Kayıt Ol" butonuna tıklayın

### Adım 2: Admin Yetkisi Verin

Terminal'de aşağıdaki komutu çalıştırın:

```bash
cd backend
pnpm make:admin <kullanici-adi>
```

**Örnek:**
```bash
pnpm make:admin admin
```

Bu komut, belirttiğiniz kullanıcıya admin yetkisi verir.

**Çıktı örneği:**
```
🔍 Kullanıcı aranıyor: admin...
✅ admin kullanıcısı admin yapıldı!
📧 Email: admin@example.com
🎉 Artık admin paneline erişebilir: http://localhost:3000/admin
```

### Adım 3: Admin Paneline Giriş Yapın

1. Tarayıcınızda `http://localhost:3000/login` adresine gidin
2. Kullanıcı adınız ve şifrenizle giriş yapın
3. Tarayıcı adres çubuğuna `/admin` yazın ve Enter'a basın
   - Tam adres: `http://localhost:3000/admin`

## 🔐 Admin Yetkisi Nasıl Verilir?

### Yöntem 1: Script Kullanma (Önerilen)

Backend klasöründe:

```bash
cd backend
pnpm make:admin username
```

### Yöntem 2: Prisma Studio Kullanma

1. Prisma Studio'yu başlatın:
   ```bash
   cd backend
   pnpm prisma:studio
   ```

2. Tarayıcıda açılan `http://localhost:5555` adresine gidin

3. "Users" tablosunu bulun ve tıklayın

4. İlgili kullanıcıyı bulun ve düzenleyin

5. "isAdmin" alanını `true` yapın

6. Değişiklikleri kaydedin

### Yöntem 3: SQL ile Direkt Güncelleme

PostgreSQL'e bağlanın:

```bash
docker exec -it instagram_clone_postgres psql -U postgres -d instagram_clone
```

SQL sorgusu:

```sql
UPDATE users SET "isAdmin" = true WHERE username = 'admin';
```

Sorguları doğrulayın:

```sql
SELECT username, email, "isAdmin" FROM users WHERE "isAdmin" = true;
```

## 🚨 Sorun Giderme

### Problem: Admin Paneline Erişemiyorum

**Çözüm 1:** Admin yetkinizin olduğundan emin olun:
```bash
cd backend
pnpm make:admin <kullanici-adi>
```

**Çözüm 2:** Çıkış yapıp tekrar giriş yapın (token yenileme)

**Çözüm 3:** Tarayıcı cache'ini temizleyin

### Problem: Script Çalışmıyor

**Çözüm:** Backend servisinin çalıştığından emin olun:
```bash
cd backend
pnpm start:dev
```

### Problem: Kullanıcı Bulunamadı

**Çözüm:** Önce normal kullanıcı olarak kayıt olun:
```bash
# Tarayıcıda
http://localhost:3000/register
```

## 📝 Hızlı Başlangıç

Tam admin kurulumu için tek komut:

```bash
# 1. Docker servislerini başlat
docker compose up -d

# 2. Backend'i başlat
cd backend
pnpm install
pnpm prisma:generate
pnpm prisma:migrate
pnpm start:dev

# 3. Yeni terminal - Frontend'i başlat
cd frontend
pnpm install
pnpm dev

# 4. Yeni terminal - Admin yetkisi ver
cd backend
pnpm make:admin admin

# 5. Tarayıcıda admin paneli aç
# http://localhost:3000/admin
```
