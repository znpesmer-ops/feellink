# PDF / canvas fontları

`NotoSans-Regular.ttf` ve `NotoSans-SemiBold.ttf` — **Noto Sans** (Google), [OFL](https://openfontlicense.org/).

Node `canvas` sunucuda sistem fontu kullanmadan Türkçe ve Latin metin çizmek için repoya eklenir; Vercel/Linux’ta Arial olmadığından bu dosyalar olmadan PDF’de □ (tofu) görünür.

Kaynak: [noto-fonts](https://github.com/googlefonts/noto-fonts) — `hinted/ttf/NotoSans/`.
